# 10000 Vocabulary

手機優先的英文單字學習與複習網站。

正式網站：

https://bellehsu.github.io/10000-vocabulary/

## 目前功能

- 首頁：顯示單字總數、歷史錯題／不熟數量、已完成頁數、最近練習正確率，並可繼續最近學習頁。
- 兩層頁碼：第一層依 `1–10`、`11–20`、`21–30`…分組；第二層只列出資料中實際存在的頁碼。
- 單字列表：搜尋英文、中文與例句，並依頁碼、詞性篩選。
- 顯示模式：中英並列、只看英文、只看中文。
- 單字卡：依單頁學習；正面顯示英文與詞性，翻面顯示中文、課本例句、翻譯、同義字、反義字、記憶提示、頁碼與難度。
- 標記不熟：單字列表與單字卡都可手動標記；練習答錯也會自動加入歷史錯題／不熟清單。
- 本頁練習：看完一頁後，只針對該頁出題，題型包含英翻中、中翻英、例句選字與易混淆題。
- 總複習：分成「歷史錯題／不熟」與「全部單字抽考」，皆可亂數抽題；全部單字可選 10、20、30、50 題或全部。
- 清除：底部分頁提供清除歷史錯題、清除學習進度、清除全部本機資料三種功能，皆有確認提示。
- 本機進度：錯題、不熟標記、已完成頁碼、最近頁碼、顯示模式與最近結果儲存在瀏覽器 `localStorage`。

## 尚待討論

- 多頁頁碼複習：之後會加入可自行選擇多個頁碼並混合亂數出題的功能；頁碼選取介面尚未定案。

## 頁碼規則

單字資料使用兩個欄位記錄頁碼：

- `page`：單字第一次出現的頁面，也是排序與頁碼篩選使用的主要頁碼。
- `page_end`：單字內容延續到的最後一頁；沒有跨頁時留空。

### 一般單字

只出現在一頁時，只填 `page`。

例如：

```csv
accustom,...,14,,5
```

表示 `accustom` 歸在第 14 頁。

### 跨頁單字

單字從前一頁開始、延續到下一頁時：

- `page` 填第一次出現的頁面。
- `page_end` 填最後一頁。
- 網頁顯示完整範圍，例如 `13–14`。
- 排序與頁碼篩選只歸在第一個出現的頁面。

目前已標記的跨頁單字包含：

- `accordingly`：13–14，歸第 13 頁
- `accumulation`：13–14，歸第 13 頁
- `addicted`：14–15，歸第 14 頁
- `aerospace`：16–17，歸第 16 頁
- `ambiguity`：18–19，歸第 18 頁

## 建議學習流程

1. 首頁選擇一個頁碼。
2. 看完該頁所有單字卡；不熟的可直接標記。
3. 按「練習本頁」，完成該頁練習。
4. 答錯的單字自動進入歷史錯題／不熟清單。
5. 再讀下一頁。
6. 需要長期複習時，到「總複習」考歷史錯題或從全部單字隨機抽考。

## 部署

這是純靜態網站，不需要登入或資料庫。

GitHub Pages 設定：

- Source：`Deploy from a branch`
- Branch：`main`
- Folder：`/(root)`

每次更新 `main` 後，GitHub Pages 會重新建置與部署網站。
