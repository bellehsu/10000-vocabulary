# 10000 Vocabulary

手機優先的英文單字複習網頁。

## 第一版功能

- 單字列表：搜尋英文、中文或例句，並依頁碼、推定詞性、熟悉度篩選。
- 翻面單字卡：英文正面；中文、例句、同義字、記憶提示與頁碼背面。
- 瀏覽器英文發音：使用 Web Speech API，不需額外語音服務。
- 測驗：英翻中四選一、中翻英四選一、英文拼字。
- 熟悉度：不熟、模糊、熟悉。
- 錯題複習：優先抽出答錯次數較多的單字。
- 本機紀錄：熟悉度、答題統計及資料問題皆儲存在 `localStorage`。
- 資料驗證：複習時可針對單字留下修正紀錄，並複製成 JSON 回報。

## 資料

- `data/vocabulary-pages-12-15.csv`：課本第 12–15 頁，共 36 筆單字。
- 欄位：單字、例句、中文、同義字／反義字、祕段落、頁碼、難度（1–5 星）。
- 詞性目前由網頁依字尾與中文內容推定；驗證時發現錯誤可直接回報。

## 部署

這是純靜態網站，不需登入或資料庫。合併至 `main` 後，可在 GitHub repository 的 **Settings → Pages** 選擇 **Deploy from a branch**，來源設為 `main` / `(root)`。

> 書頁內容由照片整理，合併跨頁項目（`accumulation`、`addicted`）。資料可在實際複習過程中逐筆驗證，不必先一次確認全部內容。
