# 10000 Vocabulary

手機優先的英文單字學習與複習網站。

正式網站：

https://bellehsu.github.io/10000-vocabulary/

## 目前功能

- 單字列表：搜尋英文、中文與例句，並依頁碼、詞性篩選。
- 顯示模式：中英並列、只看英文、只看中文。
- 單字卡：正面顯示英文與詞性；翻面後顯示中文、課本例句、中文翻譯、同義字、反義字、記憶提示、頁碼與難度。
- 發音：使用瀏覽器 Web Speech API 播放英文發音。
- 第一次練習：英翻中、中翻英、例句選字與易混淆題。
- 第二次總複習：集中處理答錯或仍不熟的單字。
- 本機進度：總複習清單、顯示模式與最近結果儲存在瀏覽器 `localStorage`。

## 頁碼規則

單字資料使用兩個欄位記錄頁碼：

- `page`：單字第一次出現的頁面，也是排序與頁碼篩選使用的主要頁碼。
- `page_end`：單字內容延續到的最後一頁；沒有跨頁時留空。

### 一般單字

只出現在一頁時，只填 `page`。

例如：

```csv
accustom,...,14,,5
```

表示 `accustom` 歸在第 14 頁。

### 跨頁單字

單字從前一頁開始、延續到下一頁時：

- `page` 填第一次出現的頁面。
- `page_end` 填最後一頁。
- 網頁顯示完整範圍，例如 `13–14`。
- 排序與頁碼篩選只歸在第一個出現的頁面。

例如：

```csv
accordingly,...,13,14,3
```

表示：

- 顯示頁碼：`13–14`
- 排序位置：第 13 頁
- 選擇第 13 頁時會出現
- 選擇第 14 頁時不重複出現

目前跨頁單字包括：

- `accordingly`：13–14，歸第 13 頁
- `accumulation`：13–14，歸第 13 頁
- `addicted`：14–15，歸第 14 頁

## 建議複習流程

### 第一輪：看單字卡

先依頁碼閱讀單字卡。

1. 看英文、詞性並先自己回想中文。
2. 按發音按鈕聽讀音。
3. 翻面確認中文、例句與記憶提示。
4. 覺得不熟的單字可直接加入「總複習」。

### 第二輪：第一次練習

完成當天的選擇題。

- 答對：顯示正確答案、中文、詞性與完整例句。
- 答對但仍不熟：手動加入總複習。
- 答錯：系統自動加入總複習。

第一次練習包含：

1. 英文選中文
2. 中文選英文
3. 例句挖空選字
4. 易混淆單字題

### 第三輪：第二次總複習

完成第一次練習後，再進入「總複習」。

- 只複習今天答錯或手動標記仍不熟的單字。
- 題目會重新洗牌並更換題型。
- 答對且已熟悉：視為今天完成。
- 答錯或仍不熟：保留到下一次複習。

## 每日使用建議

1. 先選今天要讀的頁碼。
2. 看完該頁單字卡。
3. 完成第一次練習。
4. 立刻做第二次總複習。
5. 隔天先複習前一天留下的單字，再開始新頁面。

## 部署

這是純靜態網站，不需要登入或資料庫。

GitHub Pages 設定：

- Source：`Deploy from a branch`
- Branch：`main`
- Folder：`/(root)`

每次更新 `main` 後，GitHub Pages 會重新建置與部署網站。
