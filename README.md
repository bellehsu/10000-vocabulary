# 10000 Vocabulary

手機優先的英文單字學習與複習網站。

正式網站：

https://bellehsu.github.io/10000-vocabulary/

## 目前功能

- 首頁：顯示單字總數、歷史錯題／不熟數量、已完成頁數、最近練習正確率，並可繼續最近學習頁。
- 兩層頁碼：第一層依 `1–10`、`11–20`、`21–30`…分組；第二層只列出資料中實際存在的頁碼。
- 全部單字搜尋：啟動時只載入輕量 `index.json`，可跨全部頁碼搜尋英文、中文、詞性與頁碼；點「詳細」時才載入該單字所在的 10 頁 CSV。
- 顯示模式：中英並列、只看英文、只看中文。
- 單字卡：依單頁學習；正面顯示英文與詞性，翻面顯示中文、課本例句、翻譯、同義字、反義字、記憶提示、頁碼與難度。
- 標記不熟：單字列表與單字卡都可手動標記；練習答錯也會自動加入歷史錯題／不熟清單。
- 本頁練習：只載入該頁所在的 10 頁 CSV，再針對本頁出題。
- 總複習：先從輕量索引抽題，再只下載抽中單字所需的 10 頁資料檔，不會一次下載全部完整 CSV。
- 清除：底部分頁提供清除歷史錯題、清除學習進度、清除全部本機資料三種功能。
- 本機進度：錯題、不熟標記、已完成頁碼、最近頁碼、顯示模式與最近結果儲存在瀏覽器 `localStorage`。

## 資料架構

完整單字資料固定以「每 10 頁一個 CSV」保存：

- `data/pages-011-020.csv`
- `data/pages-021-030.csv`
- `data/pages-031-040.csv`
- 後續依序為 `pages-041-050.csv`、`pages-051-060.csv`…

另外有三個輕量／驗證檔：

- `data/manifest.json`：目前頁碼、10 頁區間、CSV 路徑、單字數量與整體內容 SHA256。
- `data/index.json`：全部單字的輕量搜尋索引，只保留單字、詞性、中文、頁碼、跨頁頁碼與難度。
- `data/validation.json`：每次重建後的完整性驗證結果，包含重建前後筆數與欄位級內容 SHA256。

網站啟動時只載入 `manifest.json` 與 `index.json`。完整例句、翻譯、同義字、反義字與記憶提示在需要時才依 10 頁區間 lazy load，已載入的區間會保留在瀏覽器記憶體快取中。

## CSV 欄位

固定欄位：

`word`、`part_of_speech`、`example`、`example_zh`、`chinese`、`synonyms`、`antonyms`、`memory_hint`、`page`、`page_end`、`difficulty`

`page` 是單字第一次出現的頁面，也是分桶與篩選的主要頁碼；`page_end` 只在內容跨頁時填寫，原值在資料重整時完整保留。

## 資料完整性

`scripts/rebuild_data.py` 會在重整資料時：

1. 驗證 CSV 欄位名稱與欄數。
2. 驗證 `page`、`page_end`、`difficulty` 格式。
3. 檢查重複的 `word + page` key。
4. 以欄位值建立 SHA256，重整前後再次計算。
5. 只有在筆數相同且欄位級 SHA256 完全一致時才視為成功。

目前資料已整理至第 37 頁。

## 部署

網站使用 GitHub Pages Actions 部署。`main` 更新後會自動重新部署靜態網站；部署流程不再把多個 CSV 合併成單一大檔案。
